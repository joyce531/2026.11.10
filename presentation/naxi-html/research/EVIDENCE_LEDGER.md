## 代码对应

- `web/src/main.tsx`：React 路由，游戏首页、三个章节与 Agent 页面；`web/src/game/state.ts`：游客 `localStorage` 存档。
- `web/tools/mock_api.py` + `web/tools/agent_runtime.py`：本地 HTTP API、登录/任务/幂等和本机 SQLite 元数据；不等于已上线云端服务。
- `naxi_agents/dongba_agent.py`：标准字形与玩家图像双图 Qwen 视觉比较，质量拦截与 Mock 回退；OpenAI Responses 是未配置 Qwen 时的另一路代码路径，不称当前主运行模型。
- `services/score_omr.py`、`naxi_agents/music_agent.py`、`services/music_render.py`：图片识谱、文本规划与本地 MIDI/WAV 合成；音符需人工校对。
- `services/dance_service.py`：Wan 2.7 VideoEdit 异步提交、状态与结果下载。真实模型效果尚待人工验收。
- `data/glyphs/glyph_catalog.csv`：5 张登记字形。`data/music/music_library.sqlite3`：素材目录数据库。`data/dance/`：教学与参考媒体。
- `MILESTONE_7_REPORT.md`、`MILESTONE_8_REPORT.md`：接线/账号与定向离线测试报告，明确未作自动化真实 Qwen/Wan 验收。
