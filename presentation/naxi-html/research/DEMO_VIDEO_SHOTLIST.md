# 第 19 页：真实 Agent 演示录屏与链接

第 19 页展示三张 4:3 的实际界面截图，视频仅作为右侧的一条超链接。目前三个演示链接均未配置。录制运行中的浏览器页面；建议 16:9、H.264 MP4。须隐藏密钥、账号密码和私人媒体路径。一次任务只主动提交一次；出现 Mock 或规则回退时，画面和字幕都须明确标注。

| `links.json` 字段 | 录什么 |
| --- | --- |
| `dongba` | 打开 `/agent/dongba`；选目标字、展示标准图；在画布绘制或上传纸面照片；点一次评价；展示双图、状态、差异、建议与真实/Mock 来源。模型估计分数不得称准确率。 |
| `music` | 打开 `/agent/music`；上传有权使用的 MIDI/MusicXML/清晰印刷图；展示解析及待校对音符；人工确认；选择乐器、参考类别与旋律保留程度；生成并试听 WAV、下载 MIDI/WAV。 |
| `dance` | 打开 `/agent/dance`；用获本人同意的视频和照片；选服饰、背景；提交申请、显示审批与同一任务的异步状态；仅真实成功后播放/下载 MP4。未生成时画面止于当前状态。 |

视频录好后上传至有权访问的 HTTPS 地址，将完整链接填入 `assets/demos/links.json` 对应字段，然后从项目根目录运行 `.\.venv\Scripts\python.exe presentation\naxi-html\scripts\enable_videos.py`。未填写时维持“链接待添加”；不使用原教学视频或玩家上传原片冒充生成品。
